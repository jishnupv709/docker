## 🚀 Tech Stack
*   **Frontend:** Angular
*   **Backend:** NestJS
*   **Database:** MongoDB Atlas
*   **Containerization:** Docker (Multi-stage build)

## 💻 Local Development
1. Clone the repository.
2. Run `docker compose up -d --build`.
3. Open `http://localhost:7860`.
